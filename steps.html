Жұмыс барысы

GitHub-та командалық жобаны дамытудың қадам-қадам нұсқаулығы

1-қадам. Жобаның ағымдағы күйін жаңарту

Репозиторий орналасқан каталогқа өтіп, негізгі тармаққа ауысыңыз және соңғы өзгерістерді жүктеңіз:

git checkout master
git pull upstream master

2-қадам. Жаңа функционал үшін бөлек тармақ құру

git checkout -b feature-update
git branch

3-қадам. Жобаны толықтыру (топтық жұмыс)

Басты index.html файлын жасаңыз немесе жаңартыңыз және барлық қатысушылардың беттеріне сілтемелер қосыңыз. Файлды сақтаңыз.

4-қадам. Өзгерістерді тексеру және сақтау

git status
git add index.html
git commit -m "Қатысушылар беттеріне сілтемелер қосылды"

5-қадам. Өз тармағын GitHub-қа жіберу

git push origin feature-update

6-қадам. Pull Request арқылы модерациялау

GitHub-та өз репозиторийіңізге өтіп, Compare & Pull Request батырмасын басыңыз. Сипаттама: «Барлық қатысушылар беттерін біріктіретін басты бет жаңартылды». Содан кейін Pull Request жіберіңіз.

7-қадам. Кодты тексеру (Code Review)

Топ жетекшісі кодтың құрылымын, HTML стандарттарына сәйкестігін және файл атауларының дұрыстығын тексереді. Қажет болса, пікір қалдырады немесе түзету сұрайды.

8-қадам. Нұсқаларды басқару және біріктіру

Түзетулер енгізілген соң Pull Request қабылданады және Merge pull request арқылы негізгі тармаққа біріктіріледі. Қолданылған тармақ жойылады.
